# Условия поставки

**[Открыть сайт](https://arsen4ik6265.github.io/usloviya-postavki/)** · Портфолио-прототип · v13.0

Сервис предварительного анализа доставки: сравнение *расчётных* сценариев транспортировки, происхождения тарифных ориентиров и распределения обязанностей по договору. Это не транспортная компания, не биржа грузоперевозок и не сервис коммерческих котировок.

## Для кого и зачем

Логисты, специалисты ВЭД, закупщики и небольшие компании могут на одном экране подготовить исходные данные для запроса перевозчику, проверить базовые условия поставки и увидеть, каких сведений пока не хватает для реального решения.

## Возможности

- **Два режима:** внутри России — договорные схемы доставки без таможенных статей; ВЭД — Incoterms® 2020 с разделением расходов и перехода риска.
- **Маршрут и расстояние:** учебные направления, ручной ввод и OSRM/OpenStreetMap для *автодорожного расстояния между центрами городов*. OSRM не учитывает ограничения грузовиков и не подтверждает доступность рейса.
- **Стоимость:** отдельные справочные публикации для тентованных автоперевозок по России (20 т, FTL) с источниками и датами; другие виды транспорта и международные ставки — учебные допущения. Сведения можно заменить своими данными.
- **Срок:** для внутрироссийской фуры — модель по движению, перерывам, подготовке и обработке; для других способов — ручной ввод срока по предложению перевозчика, без искусственной автоматической оценки.
- **Сравнение:** расходы и сроки вариантов с обозначением источников. Сайт не выбирает самый дешёвый *рыночный* вариант, если ставки несопоставимы. Для направления с одним видом перевозки сравнительный график не строится.
- **Incoterms:** 7 универсальных и 4 морских базиса. Для FAS/FOB разделена ответственность за погрузку на судно. Выбранный базис показан отдельно от рекомендации по цели пользователя.
- **Контроль суммы:** итог и распределение между сторонами согласованы до копеек/центов; неучтённые таможенные платежи и услуги ясно отмечены.

## Пример сценария

Маршрут Москва → Санкт-Петербург, 20 т штучного груза, автомобильная перевозка. Сайт подставляет опубликованный ориентир стоимости тентованной фуры, позволяет проверить автодорожное расстояние и настроить дополнительные расходы. Альтернативные виды транспорта показываются с пометкой **«учебная модель»** и не объявляются объективно дешевле.

Другой пример — экспорт зерна Новороссийск → Александрия. При одинаковой модельной цепочке FOB, CFR, CIF и FAS по-разному распределяют затраты; риск по FOB/CFR/CIF переходит на борту судна в порту отправления, а по FAS — вдоль борта. Никакие результаты не являются юридической консультацией или коммерческой ставкой.

## Проверки и границы достоверности

В `TEST_CASES.md` приведены сценарии приёмки. Локальные автоматизированные тесты выполнены в Chromium с **имитированными ответами внешних API**; опубликованный сайт и живые тарифы такими тестами не подтверждаются. Проверка на iPhone и экспертная проверка реальных договоров необходимы отдельно.

Нет реальных фрахтовых котировок, расписаний ЖД/моря/авиа, проверки наличия перевозчика, ограничений портов, таможенных пошлин, санкций, транзитных разрешений или точного тарифа по адресу склада. Условные ±25% не являются статистическим доверительным интервалом. Часть расчётов обучения (например, распределение стоимости портовой обработки) — намеренно упрощённая модель, отмеченная в интерфейсе.

|---|---|
| `index.html` | Структура интерфейса |
| `style.css` | Адаптивное оформление |
| `app.js` | Расчёты, Incoterms, источники, OSRM и сравнение |
