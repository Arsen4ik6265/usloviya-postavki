# Условия поставки

Интерактивный прототип для предварительного анализа доставки груза: маршрут, ориентировочная стоимость, срок, сравнение вариантов перевозки и условия поставки.

**[Открыть сайт](https://arsen4ik6265.github.io/usloviya-postavki/)** · [Описание продуктового решения](CASE_STUDY.md) · [Требования и ограничения](PROJECT_BRIEF.md) · [Проверки](TEST_CASES.md)

## Для чего нужен

На раннем этапе организации доставки сложно быстро понять, какие расходы ожидаются, кто их несёт, насколько сопоставимы транспортные варианты и когда уместно применять Incoterms. Прототип объединяет эти вопросы в одном сценарии. Он **не заменяет тариф перевозчика, экспедитора или юридическую консультацию**.

## Как пользоваться

1. Выбрать **«Внутри страны»** или **«Международная · ВЭД»**.
2. Указать маршрут, транспорт, груз, массу и при необходимости километраж.
3. Посмотреть предварительные расходы и, где имеются данные, срок доставки.
4. Сравнить альтернативы, проверить источник ставки и изменить допущения.
5. Для ВЭД — выбрать и сравнить применимые базисы Incoterms® 2020.

## Что работает

- **Два сценария:** внутренние перевозки по России без таможенных статей и международные поставки с отдельным разделом Incoterms.
- **Автомобильные расстояния:** OSRM на данных OpenStreetMap для городов из справочника; ручное изменение расстояния и резервное значение при сбое сервиса.
- **Цены в рублях и долларах:** опубликованные ориентиры для нескольких направлений тентованных автоперевозок по России; остальные ставки — учебные или введённые пользователем. Источник и дата отмечаются рядом с расчётом.
- **Курс USD/RUB:** справочный пересчёт через JSON-зеркало данных Банка России, с ручным вводом при отсутствии доступа.
- **Срок доставки:** для внутрироссийской автомобильной перевозки — настраиваемая модель времени в пути, остановок, подготовки и обработки груза; для других видов и международных автоперевозок срок берётся из введённого пользователем предложения перевозчика.
- **Сравнение:** суммы и сроки по подготовленным сценариям, без утверждения, что учебные тарифы являются рыночными предложениями.
- **Incoterms 2020:** фильтрация базисов по виду транспорта и передаче груза, сравнение обязанностей сторон и моментов перехода риска.

## Что нельзя утверждать по результату

- Цена не является предложением на рейс: опубликованные данные относятся к конкретным датам, направлениям, типам транспорта и условиям источника. `tariffs.json` — **справочник, который обновляют вручную**, не поток живых котировок.
- Сравнение разных видов транспорта использует неодинаковые по надёжности источники: опубликованные ориентиры и модельные ставки **неравнозначны**. «Минимальная сумма» означает только минимум *при введённых допущениях*.
- OSRM строит маршрут по обычной дорожной сети, а не по правилам движения конкретного грузовика. Время OSRM — не время доставки с обработкой и остановками.
- Модель труда водителя применяется **только к внутреннему автомобильному сценарию**. Для международного рейса срок нужно уточнять у перевозчика.
- Международная перевозка не обязательно предполагает пошлины или стандартное таможенное оформление (например, для отдельных операций в ЕАЭС). Пошлины, НДС, специальные разрешения и санкционные ограничения не рассчитываются.
- Проект не проверялся экспертами отрасли и не внедрялся в коммерческую эксплуатацию.

## Данные и технологии

`HTML` · `CSS` · `JavaScript` без фреймворков · GitHub Pages · OSRM Demo / OpenStreetMap · статический `tariffs.json` · справочный курс валют.

Внешние серверы используются только для получения маршрута и курса при доступности; приложение предусматривает резервный сценарий. Ключи платных API не требуются. Данные о пользователях на сервере проекта не сохраняются.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Интерфейс двух режимов |
| `style.css` | Адаптивная вёрстка |
| `app.js` | Правила расчёта и сравнения |
| `tariffs.json` | Опубликованные ориентиры с датами и ссылками |
| `CASE_STUDY.md` | Продуктовый кейс: проблема, решения, ограничения |
| `PROJECT_BRIEF.md` | Требования и критерии приёмки |
| `TEST_CASES.md` | Контрольные сценарии и результаты проверки |
| `THIRD_PARTY_NOTICES.txt` | Лицензии и атрибуция значков |

Для запуска без установки откройте `index.html` в браузере. При локальном открытии справочник `tariffs.json` может не загрузиться из-за ограничений `file://`; в этом случае используется резервная копия данных в `app.js`. На GitHub Pages файл загружается по HTTP.

## О проекте

Это демонстрационная работа для портфолио, подготовленная с использованием AI-инструментов и проверяемая в процессе итераций. Роль в продуктовой части — определение проблемы, выбор сценариев, постановка требований, принятие решений по интерфейсу, проверка результата и уточнение ограничений. Код создавался и дорабатывался при помощи AI; самостоятельную командную разработку или коммерческое внедрение проект не предполагает.

**Актуальная итерация: v12 — повышение достоверности сроков, прозрачности источников и качества документации.**

Источники: [ICC — Incoterms](https://iccwbo.org/business-solutions/incoterms-rules/), [OSRM](https://project-osrm.org/), [OpenStreetMap](https://www.openstreetmap.org/copyright). Конкретные источники и даты тарифов см. в [`tariffs.json`](tariffs.json).
