# Условия поставки — требования к прототипу (v12)

## 1. Цель и рамки

**Задача:** помочь пользователю на раннем этапе доставки сравнить ориентировочные затраты, состав расходов, возможные сроки и договорные условия. Это поддержка предварительного решения, а не платформа заказа перевозки.

**Аудитория — гипотезы:** специалисты логистики и ВЭД, закупщики, сотрудники небольших компаний, которые готовят отгрузку. Интервью и исследование аудитории пока не проведены: это направление дальнейшей проверки, а не доказанный факт.

**Вне рамок:** онлайн-бронирование транспорта, счета и акты, гарантированные котировки, таможенные платежи и налоги, проверка грузовых ограничений, хранение профилей, коммерческое использование расчётных сроков.

## 2. Пользовательские задачи

| Сценарий | Ожидаемый результат |
|---|---|
| Внутренняя перевозка | Сумма в рублях без экспортно-импортных статей; тип договорной схемы доставки |
| Международная поставка | Стоимость в USD, справочный пересчёт в рубли, применимые Incoterms |
| Автомобильный маршрут | Расстояние OSRM при доступности, возможность исправления вручную, резервное значение |
| Выбор опубликованного ориентира | Источник, дата, ставка ₽/маш·км, заметное предупреждение об ограничениях |
| Сравнение видов транспорта | Цена, срок (если известен), источник для каждого варианта |
| Срок для внутреннего автрейса | Отдельные этапы: движение, перерывы, отдых, обработка и резерв |
| Международный автрейс | Не применять модель российского внутреннего графика; запросить срок у перевозчика |

## 3. Бизнес-правила

1. Режим «Внутри страны» исключает экспортное и импортное оформление и не показывает Incoterms по умолчанию. Это UX-решение, а не запрет на Incoterms во внутренних договорах купли-продажи.
2. Режим «Международная · ВЭД» позволяет выбрать базис Incoterms 2020 и отключить условные расходы на экспортно-импортные формальности, если они не применимы. Пошлины и НДС не рассчитываются.
3. FAS, FOB, CFR и CIF доступны только при морском / внутреннем водном транспорте и подходящей точке передачи груза. Универсальные базисы EXW, FCA, CPT, CIP, DAP, DPU и DDP доступны для разных видов транспорта.
4. Оплата фрахта и момент перехода риска — разные события: например, при CFR/CIF риск переходит при погрузке на судно, при CPT/CIP обычно при передаче первому перевозчику.
5. Для FTL-тента 20 т по России опубликованный ориентир может использоваться как ставка за машино-километр. **Не применять его автоматически** к цистернам, зерновозам и контейнеровозам.
6. Ввод пользователя имеет приоритет над автоматическим километражом. При смене маршрута/транспорта расстояние должно относиться к новому сценарию.
7. Для внутреннего автрейса срок — приближённая модель одного водителя, а не договорный срок и не проверка соблюдения законодательства. Для международного автрейса автоматический нормативный расчёт отключён.
8. Другие сроки вводятся пользователем из предложения перевозчика. Нельзя выдавать отсутствие срока за ноль или автоматически объявлять транспорт быстрее без данных хотя бы двух вариантов.
9. Стоимость, сроки и рекомендации других видов транспорта отмечаются как учебные там, где нет подтверждённого источника.

## 4. Источники и доверие к данным

| Данные | Источник | Статус и ограничения |
|---|---|---|
| Автомобильные километры | OSRM Demo / OpenStreetMap | Маршрут между центрами городов, не специализированная грузовая маршрутизация |
| Тарифы на тент по отдельным направлениям | `tariffs.json`, ссылки на публикации | Редакторская подборка, без автоматической синхронизации; дата и условия источника обязательны |
| Учебные ставки других видов транспорта | Встроенная модель | Не подтверждены рынком, не сравнимы с полноценными коммерческими предложениями |
| USD/RUB | JSON-зеркало курса Банка России | Только справочный валютный пересчёт; не тариф перевозчика |
| Сроки автодоставки внутри России | Время маршрута + пользовательские допущения | Без точных ограничений грузовиков, графика складов и подтверждения перевозчиком |
| Сроки других видов и международных автрейсов | Ручной ввод | Источник и точность зависят от пользователя |

## 5. Критерии приёмки

- Переключение Россия/ВЭД меняет валюту, доступные маршруты и юридические блоки без смешивания таможенных расходов.
- Дополнительные автомобильные расходы по умолчанию 0; доплата 5 000 ₽ увеличивает общую сумму на 5 000 ₽.
- Изменение ставки или расстояния пересчитывает сумму и сравнение.
- Сбой OSRM / курса валют не делает основной калькулятор недоступным.
- Для международного автрейса не показывается рассчитанный по российскому внутреннему графику срок. Вместо него предусмотрен ручной ввод срока из предложения.
- В сравнении явно указано происхождение каждой ставки и отличён опубликованный ориентир от учебной модели.
- Несколько вариантов могут быть сравнены по сроку только при наличии не менее двух введённых/модельных значений; недостаток данных обозначен сообщением.
- Интерфейс не имеет горизонтального переполнения на ширине 390 px; работает с клавиатуры в браузере.

## 6. Риски и границы применения

- Публикации тарифов быстро устаревают; нельзя писать «цена сегодня», если источник опубликован раньше.
- Сочетание модельной стоимости железной дороги и опубликованного ориентира автоперевозки не доказывает, что железная дорога реально выгоднее.
- Курс и дистанция могут прийти из сторонних бесплатных сервисов, у которых нет гарантии доступности.
- Слишком уверенные советы по Incoterms или таможенным процедурам могут ввести пользователя в заблуждение; требуется отраслевое ревью.
- Запрос на реальный грузовой маршрут требует специализированных исходных данных и проверки ограничений.
