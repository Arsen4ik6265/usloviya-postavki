## Проверить на реальном iPhone после публикации

- [ ] Сайт показывает v13, не старую версию из кэша.
- [ ] OSRM даёт расстояние для Москвы → Санкт-Петербурга либо показывает корректную резервную подсказку.
- [ ] Переключение FOB, CFR, CIF, FAS не ломает расчёт и меняет назначение затрат.
- [ ] Рекомендация по цели и выбранный базис различимы.
- [ ] Железнодорожный срок при изменении массы сбрасывается для новой массы.
- [ ] Смешанный ценовой рейтинг больше не называется «самым дешёвым».
- [ ] Цена авиационной альтернативы не перекрывает различия остальных вариантов.
- [ ] В Safari текст и селекты не выходят за край, нет случайного масштабирования при фокусе.
- [ ] Если пользователь меняет параметры, карточки и итог пересчитываются без зависания.
- [ ] Проверка пустых полей, отрицательного веса, неподдерживаемого маршрута и недоступного внешнего сервиса — вручную.

## Нерешённые ограничения

Портовая обработка для FAS/FOB разделена по учебной доле 65/35, а не по подтверждённому тарифу порта. Ставки по железной дороге, авиации, морю и мультимодальным схемам модельные. Нет специализированного маршрутизатора грузовиков и расписаний перевозчиков. Цель следующего этапа — упростить тексты и интерфейс после приёмки бизнес-логики.
