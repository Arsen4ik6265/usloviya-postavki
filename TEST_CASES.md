# Проверки прототипа (v12)

## Автоматизированный браузерный прогон в локальной среде

Проверки выполнены в Chromium на локальной HTML/CSS/JS версии с **тестовыми ответами OSRM, курса валют и справочника тарифов**. Результаты не подтверждают текущие ставки рынка и реальную доступность внешних API на сайте GitHub Pages.

| Сценарий | Ожидаемое поведение | Итог локальной проверки |
|---|---|---|
| Открытие главной страницы | По умолчанию «Внутри страны», Москва — Санкт-Петербург | Пройдено |
| Внутренняя перевозка | Нет экспортных и импортных строк расходов | Пройдено |
| Платные дороги + 5 000 ₽ | Итог увеличивается ровно на 5 000 ₽ | Пройдено |
| Источник цены | Опубликованный автомобильный ориентир отделён от учебной альтернативы | Пройдено |
| Международный режим | Появляются ВЭД и Incoterms, меняется готовый маршрут | Пройдено |
| Международный автрейс | Не используется модель нормативов российского внутреннего водителя | Пройдено |
| Международный автрейс + ручной срок 6 суток | В сравнении появляется «6 сут.», без `NaN` | Пройдено |
| 390 px и 1280 px | Нет горизонтального переполнения | Пройдено |
| JavaScript | Нет необработанных ошибок во время прогона | Пройдено |

## Чек-лист для проверки на реальном iPhone

- [ ] После публикации видно последнее обновление v12, а не файл из кеша.
- [ ] Выбор другого направления корректно меняет расстояние и источник цены.
- [ ] OSRM показывает действительный результат или резервную подсказку, не блокируя ввод вручную.
- [ ] Переключение между Россией и ВЭД не оставляет чужие таможенные строки.
- [ ] Выбор FAS/FOB/CFR/CIF соответствует морскому варианту и точке передачи.
- [ ] Отключение оформления в ВЭД убирает соответствующие модельные суммы.
- [ ] В международном автомобиле видна просьба указать срок перевозчика, а не нормативный срок российского внутреннего рейса.
- [ ] Источник и дата отображаются рядом со ставкой, учебные альтернативы помечены.
- [ ] Ввод срока перевозчика не вызывает ошибок и обновляет карточки.
- [ ] Сайт читаем без горизонтальной прокрутки в Safari.

## Известные ограничения тестирования

Внешние сервисы могут изменять ответ или перестать быть доступны. Юридическая корректность Incoterms и применимость тарифов требуют проверки специалистом. Пользовательские исследования целевой аудитории и нагрузочные испытания не проводились.
