# Версия 17 — интерфейс расчёта

- Маршрут, груз, сумма, источник ставки и срок собраны в одном блоке результата.
- Подробности расчёта и дополнительные настройки раскрываются по запросу.
- Сравнение представлено компактным списком; график открывается отдельно.
- Для единственного сценария действие ведёт к расходам.
- На телефоне добавлена навигация по разделам без большой перекрывающей кнопки.
- Ошибки ввода расположены рядом с полями и связаны с ними через aria-describedby.
- Фокус графика сохраняется при переключении; введённые сроки обновляют график.
- Сохранены исходная палитра и система выбора темы.

Загрузка с телефона:
1. Распакуйте ZIP.
2. Загрузите файлы из архива в корень существующего репозитория с заменой.
3. Сам ZIP на GitHub загружать не нужно.
4. После публикации GitHub Pages обновите страницу. index.html запрашивает ресурсы с ?v=17.
